# 客户端配置表对拍结论（方法 + 结论摘要）

> 本文是**结论摘要**，供仓库归档用。原始数据表（含官方数值明细）留在逆向工作目录，不随仓库分发。
> 数据来源：《率土之滨》客户端配置表 `tb_cfg_skill` / `tb_cfg_skill_detail` / `tb_cfg_skill_effect` / `tb_cfg_hero` 等；权利归属见 `NOTICE.md`。

## 一、对拍方法

配置表为 MemoryPack 序列化，结构统一：

```
[u32 字符串池字节长][池: u32 条数 + (u32 字符数 + UTF-16LE)×N]
[u8 propCount][u32 键数][i32 键×N][u32 行数][行…]
行内: [u8 objectHeader(=字段数)] + 按 ReadUnmanaged 分组顺序取字段（int 4B / sbyte 1B，混排无填充）
      字符串字段 = i32 字符串池索引（-1 ⇒ null），非内联
```

验收判据（三者同时成立才算解析成功）：**键数 == 行数** ∧ **首字段与键逐位一致** ∧ **数据区残差 == 0**。

口径换算：
- 武将属性 = 整数 `÷100`（`attack_base 9900` ↔ `99.0`）
- 战法效果值 = `constant_param + 0.4 × intel_param`（`0.4 = 80/200`，即官方文案「受XX属性影响」在属性 80 时的取值）
- 发动率 = `probability_max ÷ 100`（满级口径）

## 三、条件字段语义（已破译）

| 字段 | 编码 | 语义 |
|---|---|---|
| `condition` | `1000+百分比` | **自身**兵力低于初始兵力的 N% |
| | `2000+百分比` | **目标**兵力高于初始兵力的 N% |
| | `30xx` | 兵种/伤害类型条件 |
| | `2xxxx` | 士气/次数类阈值 |
| `precondition` | **武将 id**（100xxx 段，126/126 命中） | **队伍里需要该武将**（协同/羁绊条件） |
| `cast_condition` | `[源子技能 id] × 1000 + [机制码]` | **当某源战法的某机制发动时本槽位才生效**（机制联动门） |

`condition` 与 `precondition` 经文案共现逐条验证（如 `1025`↔「自身兵力低于初始兵力25%」；吕布+貂蝉两条 `precondition` 同现于「善战无前XP」）。

## 四、引用展开（口径统一）

`effect_id = 122`「子技能（有益）」/ `123`「子技能（有害）」是**效果组引用容器**，非真机制：

```
122/123 槽位 → constant_param = 被引用子技能的族 id
              → detail_id // 100 == constant_param 定位该族，取其槽位的 effect_id
              → 族内仍有 122/123 则递归
```

命中率：`122` 1946/1947、`123` 60/60（唯一落空是 `const=0` 空引用）。

以官方 `tb_cfg_skill_effect_map`（706 条「战法→机制码」）为靶：

```
不展开   218/384 = 56.8%     ← 未展开时容器码造成大面积假差异
展开后   337/384 = 87.8%
剩余 47 条为单向差异：官方码集 ⊂ 引擎码集（官方更多 = 0 条）
```

⇒ 官方表是**主机制摘要**，引擎展开后为其**严格超集**。例：安抚军心 官方仅列「急救」，引擎多出「镇静」，而「镇静 = 移除有害效果」正是该战法实际作用。

## 五、未解项（如实记录）

1. `cast_condition` 的 78 个前缀（前两位 12/32/22/42/13/34）未能归属到已知战法（已归属 15 个，偏移为子技能段 `+10000/+20000/+30000`）。
2. 展开后剩 47 条差异中，可能混有**共享子技能带出的过度展开**——精确判定需把 `condition`/`cast_condition`/`precondition` 纳入展开条件（本轮未做）。
3. `precondition` 的非武将值（如 `-6000/-80/80/3/19`）疑为组合标志位，未定论。

## 六、已否证的假设（避免重复投入）

- `cast_condition` 大值**不是** `tb_cfg_skill` 主键、**不是** `skill_detail` 的 `detail_id`、**不是任何** tcfg 表主键（扫 2,608 张表 + 字节级 u32/i32/ASCII 搜索）。
- 伤害/增减伤结算**不在客户端**，客户端只有配置表 + 战报回放。
